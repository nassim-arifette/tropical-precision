# Manuscript

**Contextual Precision in Tropical Abstract Domains: Sharp Generator Budgets and ReLU Certificates**

Nassim Arifette

[Read the paper](main.pdf).

This directory is the canonical source of the manuscript intended for arXiv. The GitHub PDF and the arXiv preview are generated by the same build and contain the same paper. No arXiv identifier has been assigned yet.

## Files

| Path | Contents |
|---|---|
| `main.tex` | Main document and abstract |
| `preamble.tex`, `authors.tex` | Formatting, notation and author |
| `sections/` | Main text and bibliography |
| `appendices/` | Additional proofs and reproduction details |
| `figures/relu-merge.tex` | Editable TikZ source for the certificate-recovery figure |
| `main.pdf` | Compiled manuscript |

The figure is drawn directly by LaTeX. It needs no external image files or plotting data.

## Build

Install Python 3.11+ and a TeX distribution containing PDFLaTeX, TikZ, Latin Modern, AMS packages, geometry, microtype, booktabs, tabularx, hyperref, bookmark and xurl. A standard TeX Live or MiKTeX installation can provide these packages.

From the repository root:

```sh
python -B scripts/build_paper.py
```

The script runs PDFLaTeX three times, checks for unresolved references and overflowing boxes, and writes `paper/main.pdf`. Logs and auxiliary files stay in `.build/paper/`. No BibTeX run or shell escape is required.

For the arXiv upload, run:

```sh
python -B scripts/build_paper.py --arxiv
```

This also produces `arxiv/arxiv-source.zip`, containing the exact same LaTeX sources and figure, and a byte-identical PDF at `output/pdf/arxiv.pdf`. These two generated directories are ignored by Git. Upload the ZIP to arXiv and inspect the PDF generated by its server before submitting. The script does not submit the paper.

Edit the manuscript here and rebuild both outputs with `--arxiv` when preparing a submission.
